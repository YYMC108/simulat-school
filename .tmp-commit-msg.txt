feat: 大学生活模拟器引擎核心 + 命令行试玩 + 数值平衡模拟器

数据驱动的文字养成游戏。16 周学期、6 项属性、17 个事件、10 种结局。

架构（三层单向依赖，引擎零浏览器依赖）：
- src/engine  纯 TypeScript 引擎：条件/效果 DSL、种子 RNG、相位控制
- src/data    数据层：数值配置、行动、事件、结局
- src/cli     界面层：交互式试玩 + 数值平衡模拟器
- tests       17 个单元测试

关键设计：
- 条件与效果用判别联合写成数据，改数值不用碰引擎代码
- 注入随机种子，整局可复现（单元测试与批量模拟的基础）
- maybeAdvance() 作为时间推进的唯一闸门，事件未处理完自动冻结时间
- 恒真兜底结局 + 对应的单元测试，保证游戏永不卡死

平衡调优（由 simulate 跑 3000 局发现）：
- 引入每周属性衰减，解决 48 次行动把属性顶满的问题
- 拆分坏结局的失败维度，修复「情绪崩溃」永远触发不到的死结局
- 下调心情衰减与崩溃阈值，让好结局不再被坏结局堵死

踩坑记录见 README 末尾与 docs/引擎导读.md
